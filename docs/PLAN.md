2. **Stripe** — subscription plans (business/enterprise), billing portal, webhook → update org plan

5. **AI Ticket Assistance** — plain text → auto-fill ticket fields (Business+); parsing for SMS/email (Enterprise)
6. **Department Hierarchy** — manager role, dept-scoped tickets/reports, enable/disable toggle
7. **QR Org Joining** — QR from join code, scan → pre-filled join page
8. **Browser Extension** — see `docs/BROWSER-EXTENSION-PLAN.md`
